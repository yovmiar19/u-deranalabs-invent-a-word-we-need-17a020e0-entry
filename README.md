Inventing one new English word that fills a real gap, with a one-line definition:

> **Plancelief (n.): The guilty relief you feel when someone else cancels plans you were secretly dreading.**

The program (`main.ts`) writes exactly that line to `/output/entry.txt` (103 characters, inside the 1–140 gate) and reads the file back to verify the written text matches the line exactly.
